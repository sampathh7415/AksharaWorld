# Claude Opus 4.7 Browser Demo

The "Claude Opus 4.7 — Browser Demo" is a professional, self-contained AI chatbot interface.

### Key Features
- **Real AI Integration**: Powered by `Puter.js` for free, browser-based AI calls.
- **Glassmorphic Design**: Modern aesthetic with backdrop filters, subtle gradients, and premium color tokens.
- **Dark Mode Support**: Fully responsive theme switching with persistence.
- **Conversation Management**: Automatically saves chat history to `localStorage`.
- **Markdown Support**: Rich text rendering via `Marked.js` and `DOMPurify`.
- **Responsive Layout**: Optimized for desktop, tablet, and mobile viewing.

### How to Use
1. Open the [index.html](file:///C:/Users/Lenovo/.gemini/antigravity/scratch/claude-opus-demo/index.html) file in your browser.
2. The interface will initialize the AI (Puter.js).
3. Use the quick-start chips or type a message in the composer.
4. Your conversations are saved locally and will persist across refreshes.
