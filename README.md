## What is Sam?
Sam is a local AI agent that:
- Runs completely offline on your laptop (using Ollama)
- Syncs seamlessly to your mobile (React Native)
- Never sends data to cloud unless you choose to
- Remembers conversations, learns your preferences
- Manages tasks, analyzes metrics, makes decisions
- Works instantly (no API latency, no rate limits)
## Sam's 5-Layer Architecture
**Layer 1: Brain** - Local Ollama models (qwen3.6, gemma4, llama3) at http://localhost:11434/v1
**Layer 2: Memory** - SQLite + JSON (conversations, preferences, tasks, decisions, metrics)
**Layer 3: Sync** - Offline-first CRDT (works offline, syncs automatically when online)
**Layer 4: Multi-Device** - Laptop (Electron), Mobile (React Native), Web (Next.js dashboard)
**Layer 5: Integrations** - Razorpay, Telegram, Firebase, Google Sheets, GA4, Blogger, Gmail
