# Product Roadmap

## Phase 1: MVP ✅ (Current)

- [x] Authentication (JWT + refresh)
- [x] Real-time dashboard
- [x] Customers, products, orders, payments
- [x] WebSocket live updates
- [x] Notifications center
- [x] Staff roles (Admin, Manager, Staff)
- [x] Docker deployment
- [x] Audit logging

## Phase 2: Business automation

- [ ] PDF/CSV export (orders, customers, revenue)
- [ ] Invoice generation per order
- [ ] Email notifications (SendGrid/SES)
- [ ] SMS alerts (Twilio)
- [ ] Scheduled reports
- [ ] Granular permissions per module

## Phase 3: Scale

- [ ] Multi-branch / warehouse support
- [ ] Multi-tenant SaaS (org isolation)
- [ ] Job queue (BullMQ) for async tasks
- [ ] Advanced Redis caching layers
- [ ] Horizontal scaling + Socket.IO Redis adapter
- [ ] Observability (Prometheus, Grafana, Sentry)

## Phase 4: Advanced features

- [ ] AI sales insights and forecasting
- [ ] Customer segmentation
- [ ] Fraud detection on payments
- [ ] Native mobile app (React Native)
- [ ] Stripe/Razorpay/PayPal live integrations
