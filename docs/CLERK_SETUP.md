## CLERK SETUP GUIDE (Free Tier — Owner Only)
# Do this once. Takes 5 minutes.

## Step 1: Create Free Clerk Account
1. Go to: https://clerk.com
2. Sign up with your Google/GitHub account
3. Create new application: "Akshara World Dashboard"
4. Choose "Email" and "Google" as sign-in options

## Step 2: Get Your API Keys
After creating the app, go to:
Dashboard → API Keys → Copy these two keys:

NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_test_...
CLERK_SECRET_KEY=sk_test_...

## Step 3: Add to .env.local
Add these lines to: c:\akshara-dashboard\.env.local

NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_test_YOUR_KEY_HERE
CLERK_SECRET_KEY=sk_test_YOUR_KEY_HERE
NEXT_PUBLIC_CLERK_SIGN_IN_URL=/sign-in
NEXT_PUBLIC_CLERK_SIGN_UP_URL=/sign-up
NEXT_PUBLIC_CLERK_AFTER_SIGN_IN_URL=/
NEXT_PUBLIC_CLERK_AFTER_SIGN_UP_URL=/

## Step 4: Restrict to Owner Only
In Clerk Dashboard:
- Go to: User & Authentication → Restrictions
- Enable: "Allowlist" mode
- Add your personal email to the allowlist
- This ensures ONLY you can log in

## Step 5: Enable 2FA
In Clerk Dashboard:
- Go to: User & Authentication → Multi-factor
- Enable: "Authenticator application" (TOTP)
- Mark as: Required (not optional)

## Step 6: Restart Dashboard
After adding keys, restart: npm run dev (in c:\akshara-dashboard)

## CURRENT STATUS
Auth is built into layout.tsx via ClerkProvider.
The /sign-in and /sign-up pages are auto-generated by Clerk.
Once keys are added, login will be required to access the dashboard.
